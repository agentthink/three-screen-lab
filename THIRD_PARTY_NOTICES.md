# Code and asset permissions

Original project code, procedural model geometry and contributor-authored documentation use the root [MIT license](LICENSE). Third-party components retain their own permissions. The current runtime maps and geographic textures use **public-domain Natural Earth data**, replacing the earlier DataV, Esri and Three.js example imagery.

The agriculture, industry and park scene geometry and SVG header effects adapt the owner's [big-screen-astra](https://github.com/yinweinidongle/big-screen-astra) project with their explicit reuse permission. Adapted code is distributed under this repository's MIT license. The [permission record](docs/licensing/astra-owner-permission.txt) identifies the source commit and scope; [implementation notes](docs/astra-cases.md) describe the redesign. The three original generated header backgrounds are included with owner authorization under the separate generated-art policy below. No upstream font files are included.

Natural Earth's [primary terms](https://www.naturalearthdata.com/about/terms-of-use/) explicitly allow commercial use, modification and redistribution. The retained [permission record](docs/licensing/natural-earth-PUBLIC-DOMAIN.txt), [pinned source archives](config/asset-sources.json) and [runtime inventory](assets/manifest.json) provide a reproducible provenance chain. Normal builds use committed derivatives without contacting a map service. See [regeneration instructions](docs/assets.md).

Upstream boundary conventions and small-scale generalization can differ from the previous provider. The grouping of regions preserves the demo UI; no old coordinates or raster pixels are inputs to the replacement pipeline. Maps and statistics are illustrative. Reference images, original CAD and third-party trademarks are not licensed by this repository. Earlier Git history retains its historical permission status; the clearance described here concerns the current map/texture files and newly rebuilt downloads.
