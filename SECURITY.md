# Security

These dashboards are static visual demonstrations. They do not implement authentication, device control or a production data service. Only the current `master` branch is maintained; no support window is promised.

Do not include passwords, tokens, private datasets or exploitable details in public issues. Use the repository's **Security → Report a vulnerability** option if available, or request a private contact channel from the maintainer without disclosing the vulnerability. A normal rendering bug can use the bug template.

Before integrating a real service, keep credentials on a trusted backend, validate and escape incoming text, and review third-party asset permissions. Do not place credentials into generated HTML, screenshots, source archives or browser tests.
