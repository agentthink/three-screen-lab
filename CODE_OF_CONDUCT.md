# Community conduct

We want contributors with different backgrounds and skill levels to feel welcome.

- Discuss the work with respect. Offer concrete, actionable feedback and assume good intent.
- Welcome questions, credit contributions, and allow people time to learn.
- Do not harass, threaten, discriminate, publish private information, or repeatedly disrupt discussion.
- Keep reports and reviews relevant to the project. Do not post personal attacks or unrelated promotions.

This applies to the repository's issues, pull requests and other project-controlled spaces. Maintainers may edit or remove inappropriate content, close disruptive discussions, and restrict participation. They should explain the action when appropriate, handle reports discreetly and recuse themselves when personally involved.

Report a concern to the repository owner through the contact options on [the maintainer's GitHub profile](https://github.com/yinweinidongle). If no private contact is available, ask for a private channel without posting sensitive details publicly. We do not promise a response time or confidentiality guarantees that GitHub itself cannot provide. Respectful disagreement with a technical decision is welcome.
