# Smart Factory

Source code: `src/screens/factory/`.

`model.js` builds the cooling towers, main factory buildings, storage tanks, pipelines, roads, and supporting structures. `app.js` handles panel data and user interactions. The exported 3D model is stored at `assets/models/factory-campus.glb`.

Drag with the mouse to orbit around the factory, use the scroll wheel to zoom, and select a building to display its information.

Use `#factory-theme-toggle` to switch between day and night themes. A shader-based light sweep transitions from left to right over approximately 1.6 seconds. The night scene retains a very fine grid, blurred glow, and Fresnel outlines. Depth occlusion is used to prevent duplicate edge lines. The grid texture is procedurally generated by the project and is provided under the MIT license, allowing commercial use and redistribution.

If WebGL is unavailable, a generated fallback image of the factory campus is displayed instead.

To rebuild the factory scene, run:

`npm run build:factory`

To preview it, open:

`http://127.0.0.1:5173/factory.html`

When modifying materials, check all four states: daytime, the middle of the transition, nighttime, and the transition back to daytime.

The charts and production figures use demonstration data. This is not a real-world industrial engineering model.
